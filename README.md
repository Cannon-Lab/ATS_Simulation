# ATS_Simulation

 This repo provides the parameter file (Muscle_ATS.xlsx) and simulation tips to generate the Figures from our study, "**Potassium-Sensitive Loss of Muscle Force in Murine Models of Andersen Tawil Syndrome**" by Elia et al.

 All simulations begin with the same set of parameters, which represent the wild-type case. The amplitude of the inward rectifier K current (*IKir*) is then attenuated by scaling over a range from 1.0 -> 0.0 to recreate various features of ATS.
